# v2.0.0

## Biggest changes

**Every ticket branch now works in a draft PR**
- The skill that creates the branch opens a draft PR right away. Every later skill posts its report there, and the issue keeps only the spec.
- Spec changes you approve go on both the issue and the PR as a short `Spec amendment` note. The issue body never changes.
- PR bodies fold the details. Summary and the revert verdict stay open, and everything else opens on click.
- `For the reviewer` sorts items into red (bugs), yellow (needs your call) and green (notes) boxes.
- `pr-ticket` can now run from any session once a branch is ready, and Claude starts it on its own. It marks the PR ready, or leaves it a draft while red or yellow items remain.

**`architect-ticket` writes the interface in your editor**
- It writes one function at a time straight into its source file, then argues for it in chat without pasting code. Say "ok" or ask for a change.
- It writes all the tests in one go after that, without asking you to approve their names.

## Breaking, renamed, or removed
- `challenge-pcr` is now `amend-pcr`.
- `grilling` is merged into `grill-docs`. Type `/grill-docs` or say "grill me".
- kanban-ci is retired. Run `claude plugin uninstall kanban-ci@custom-skills`, and delete `.github/workflows/kanban-ci.yml` from any project that used it.

## New skills
- `amend-pcr` loads when a PCR (a project convention in `docs/pcr/`) blocks the work. It changes the PCR only after you approve.
- `helper-skill` shows up in your skill list but does nothing on its own. It holds files the kanban skills share. You can ignore it.

## Changed skills
- `grill-docs` updates `CONTEXT.md` and the ADRs and PCRs as decisions settle. Claude can start it on its own, and other skills use it for their interviews.
- `new-ticket` and `map-epic` use new effort levels. `major` means a new file, a behaviour change across files, a change to a function more than one other file calls, or no clean revert. `medium` means a public interface change or a needed ADR or PCR.
- `effort:trivial` and `effort:minor` branches end with `/review-diff`, then `/pr-ticket`.
- `review-diff` turns drift you call intentional into a Spec amendment.
- `execute-ticket` hands its branch to `pr-ticket` instead of writing its own PR.
