Using both Claude Code and Codex? Install each marketplace in its own tool. They ship the same 18 skills and don't clash.

Before you start

  • Claude Code or Codex installed and logged in.
  • The gh command line tool, logged in with gh auth login. The kanban skills (map-epic, new-ticket, and the four *-ticket workflow skills) file tickets as GitHub issues and stop without it. The other skills don't need it.

Claude Code marketplaceRecommended

1

Add the marketplace

Start Claude Code anywhere and type:

/plugin marketplace add Maxastrand04/Custom-skills

This tells Claude Code where the skills live. It installs nothing yet.

2

Install the plugin

/plugin install max@custom-skills

A panel opens with the plugin's details. Confirm the install there.

3

Load it

/reload-plugins

Restarting Claude Code does the same.

4

Check it worked

Type /max: and the list should show 18 skills. Try one:

/max:brainstorming a CLI that renames photos by the date they were taken

Every skill from the plugin starts with max:. The other sheets write them without it, so /map-epic there means /max:map-epic for you.

Prefer a shell? These do steps 1 and 2:

claude plugin marketplace add Maxastrand04/Custom-skills
claude plugin install max@custom-skills

You get the kanban skills, the developer tools, and the behaviour skills. The developer skills sheet covers what each one does and where to start.

Codex marketplaceRecommended

Same 18 skills as the Claude Code marketplace, built for Codex.

1

Add the marketplace

In a terminal, run:

codex plugin marketplace add Maxastrand04/Custom-skills

This tells Codex where the skills live. It installs nothing yet.

2

Install the plugin

codex plugin add max@custom-skills-codex

The marketplace is called custom-skills-codex, not custom-skills like the Claude Code one.

3

Check it worked

Start Codex and type /skills. The max: skills should be in the list. Try one:

$max:brainstorming a CLI that renames photos by the date they were taken

Codex calls skills with $, not /. The other sheets write /map-epic, which means $max:map-epic for you. Restart Codex if the skills don't show up.

Updating and removing

Claude Code

Pull the latest skills:

/plugin marketplace update custom-skills

Remove them:

/plugin uninstall max@custom-skills

Codex

Pull the latest skills. The first command fetches the new version, the second installs it:

codex plugin marketplace upgrade custom-skills-codex
codex plugin add max@custom-skills-codex

Remove them:

codex plugin remove max@custom-skills-codex

install.sh and making your own

The marketplaces give you a copy you can't edit. If you want to change a skill, write new ones, or treat this repo as the base for your own set, fork it and use install.sh instead. It also offers the schoolwork skills, which the marketplaces leave out.

The short version:

# fork Maxastrand04/Custom-skills on GitHub first, then
git clone https://github.com/<you>/Custom-skills.git ~/GitHub/Custom-skills
cd ~/GitHub/Custom-skills
./install.sh            # menu, pick Claude Code, Antigravity, or Codex

For Claude Code and Antigravity, the script links each skill folder into ~/.claude/skills/ (or Antigravity's skills folder), so they read straight from your clone. Edit a SKILL.md and the next run of that skill uses the new version. Nothing to reinstall.

Codex works differently. The script builds Codex copies of the skills inside your clone and links those into ~/.agents/skills/. After you edit a skill or pull changes, run ./install.sh --codex again to rebuild the copies. It needs Python 3.9 or newer.

Skills installed this way have no prefix, so it's /grilling in Claude Code and $grilling in Codex, not /max:grilling.

The README walks through it step by step: the menu, adding your own skills, and pulling in my changes later.

Already installed from a marketplace? Remove it first with /plugin uninstall max@custom-skills or codex plugin remove max@custom-skills-codex, so you don't end up with two copies of every skill.
